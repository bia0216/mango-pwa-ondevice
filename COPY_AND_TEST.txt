MANGO GRADER ON-DEVICE (v3: all models + heat maps on the phone): COPY AND TEST

1. GET THE NEW MODEL FILES
   Download from Google Drive: mango_project/ondevice/mango_ondevice_keras_models.zip (66 MB).
   Extract it INTO your app's models folder (next to index.html). Replace models.json when Windows asks.
   The models folder must then hold 11 files:
     detector.onnx
     ripeness_yolo.onnx, disease_yolo.onnx
     ripeness_mobilenetv2.onnx, disease_mobilenetv2.onnx
     ripeness_effnetv2b0.onnx.part0, ripeness_effnetv2b0.onnx.part1
     disease_effnetv2b0.onnx.part0, disease_effnetv2b0.onnx.part1
     models.json   (the NEW one: it lists all 7 models)

2. COPY THE APP FILES from this zip into the app folder (replace the old ones):
     index.html, app.js, ondevice.js, sw.js, style.css, manifest.webmanifest, README.md, icons\

3. TEST ON THE LAPTOP (VS Code -> right-click index.html -> Open with Live Server)
   - Ripeness tab: the Model list shows "MobileNetV2 · on phone" (default), "EfficientNetV2-B0 · on phone",
     "YOLO26n-cls · on phone". Upload a photo with 2-3 mangoes -> numbered boxes, one chip per mango.
   - Disease tab: default "EfficientNetV2-B0 · on phone". Upload a mango with spots -> boxes AND a heat map
     on each mango; note "Red = where the disease model looked most". Try a leaf photo too.
   - Try each model once (the first use of each model loads it: 6-24 MB).
   - F12 -> Console: no red errors (a 404 means a model file is missing from the models folder).

4. UPLOAD TO GITHUB (repo mango-pwa-ondevice)
   a) App files: Add file -> Upload files -> "choose your files" ->
      index.html, app.js, ondevice.js, sw.js, README.md -> Commit changes.
   b) Model files: open the models folder on GitHub -> Add file -> Upload files -> "choose your files" ->
      the 7 new files (ripeness_mobilenetv2.onnx, disease_mobilenetv2.onnx, the 4 .part files) AND models.json
      -> Commit changes. Every file is under 25 MB, so the web upload accepts them.
      (If the models folder does not exist yet: Add file -> Create new file -> name  models/README.md  -> commit,
       then upload ALL 11 files into it.)
   - Wait 1-2 minutes: https://bia0216.github.io/mango-pwa-ondevice/

5. TEST ON THE PHONE
   - With internet: open the link, refresh twice, scan once with each model you want offline (this saves it).
   - Airplane mode: close and reopen the app, scan again. Ripeness, disease AND heat maps should still work.

Never upload API keys. The presented app (mango-pwa) is not part of this.
